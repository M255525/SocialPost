操作手冊

社群貼文產生器依 Facebook／Instagram／X／Threads 各自的字數上限與語氣慣例，把同一份主題內容改寫成四種平台優化版貼文；Facebook 可直接登入帳號自動發布，其餘平台複製文字後手動貼上即可。

操作步驟

  1. 在「貼文素材」輸入主題、方向，或直接貼上一段現成草稿
  2. 選擇語氣（親切口語／專業正式／促購優惠／正式公告），勾選要發布的平台（可複選）
  3. 選用：上傳圖片（可多張）或一支影片，會顯示縮圖預覽
  4. 選用：展開「AI 優化設定」填入你自己的 API 金鑰，讓語言模型依各平台特性改寫文案；不填金鑰也能使用「規則式引擎」產生基本版本
  5. 按「產生優化貼文」，下方會出現每個平台各一張預覽卡，內容可直接在文字框中微調
  6. Facebook 卡片：登入帳號、選擇粉專後按「發布到 Facebook」即可直接發文；其餘平台按「複製文字」自行貼到該平台 App／網站發布

AI 優化設定（選用，需自備 API 金鑰）

「產生優化貼文」預設會使用本機規則式引擎（依平台字數上限截斷、從主題挑關鍵詞組 hashtag），效果陽春但完全不連網。若想要語意更好的改寫，可以自己接上語言模型：

  1. 展開「AI 優化設定」，選擇服務商（Claude／OpenAI／Gemini／OpenRouter），填入你自己申請的 API 金鑰；模型欄有預設值，也可自行改成想用的模型 ID
  2. 按「產生優化貼文」時，若金鑰有填就會自動改用 AI 產生；若某個平台的 AI 結果解析失敗，該平台會自動退回規則式引擎，並在產生結果下方提示
API 金鑰只存在你這台電腦的瀏覽器（localStorage），使用時依你與該服務商的方案計費，本工具不會向你收費，也不會經手你的金鑰。

Facebook 自動發布設定

Facebook 卡片透過官方 Facebook JavaScript SDK 讓你用自己的帳號登入並發布到你管理的粉專，本工具不會經手或保存你的 Facebook 帳密。使用前你需要：

  1. 已有 Facebook 開發者帳號與一個 Facebook App（在 developers.facebook.com 建立），並取得 App ID
  2. 該 App 的「應用程式網域」與「有效的 OAuth 重新導向 URI」需要加入你實際開啟本工具的網址（例如本機測試用 http://localhost:8778）
  3. 你的 Facebook 帳號要有欲發文粉專的管理員權限

操作流程：

  1. 在 Facebook 卡片填入你的 App ID（會存在瀏覽器中，下次不用重填）
  2. 按「登入 Facebook」，跳出的 Facebook 官方視窗中授權 pages_show_list、pages_manage_posts、pages_read_engagement 權限
  3. 登入成功後下拉選單會列出你管理的粉專，選擇要發布的粉專
  4. 按「發布到 Facebook」，確認彈出的提示後送出——若有上傳圖片會一併發布單張／多張相片貼文，有上傳影片則發布為影片貼文，都沒有就是純文字貼文
請注意：
  • 發布後的內容會公開出現在你選定的粉專上，且無法透過本工具復原，請發布前務必再次檢查內容
  • 登入權杖（access token）只存在你的瀏覽器 localStorage，請勿在共用電腦上使用這個功能，也不要把网址或畫面截圖分享給他人
  • 目前只有 Facebook 支援自動發布；Instagram／X／Threads 需要各自不同的 API 與審核流程，本工具僅提供文案優化與複製，不做自動發布

各平台優化邏輯

  • Facebook：字數上限寬鬆，語氣親切、鼓勵留言互動，篇幅可以稍長，適合說故事
  • Instagram：建議 150-300 字，開頭第一句要抓住眼球，多用 emoji 與換行分段，hashtag 集中放在文末（8-15 個）
  • X（Twitter）：硬性上限 280 字，簡短有力，hashtag 最多 1-2 個
  • Threads：上限 500 字，語氣輕鬆對話感，像跟朋友聊天

隱私說明

  • 主題內容、語氣、平台勾選會存在瀏覽器 localStorage（草稿），關閉分頁後下次打開仍會保留，但不會傳送到任何伺服器
  • AI API 金鑰與 Facebook App ID／登入權杖都只存在瀏覽器 localStorage，換一台電腦或清除瀏覽器資料就會不見
  • 按「產生優化貼文」若填有 API 金鑰，主題內容會直接連線送到你選擇的服務商官方 API，不會經過本工具作者或任何第三方伺服器
  • 按「發布到 Facebook」會直接連線到 Facebook 官方 Graph API，發布內容與所選粉專資訊只在你與 Facebook 之間傳遞

使用警語

請注意：
  • 本工具的規則式引擎完全不連網；只有填入 API 金鑰並按下「產生優化貼文」，或使用 Facebook 登入／發布功能時才會對外連線
  • 請勿在任何欄位輸入真實個資、公司機密、他人受著作權保護的內容，或不希望被 AI 服務／Facebook 留存的敏感資訊
  • AI 的回覆可能包含錯誤或過時資訊，發布前務必自行查證並確認符合各平台社群守則
  • 使用 AI 優化功能所產生的 API 費用由你與所選服務商的方案自行負擔，本工具不會向你收費
  • Facebook 發布為公開且不可復原的動作，本工具與創作者不對發布後的任何結果或後續影響負責
  • 僅供教學、課程及個人使用，禁止未經授權公開發布、販售或商業化使用
