一份主題，四種平台優化貼文

輸入主題、方向或現成內容，依各平台字數與語氣慣例產生優化文案；Facebook 可直接登入自動發布，其餘平台複製貼上即可手動發布。另有「留言回覆」分頁，針對粉絲留言產生多種角度的回覆建議。

1貼文素材

輸入主題、方向或一段完整草稿都可以，AI（或規則式引擎）會依下方勾選的平台各自改寫成優化版本。

這裡填寫的內容會附加在送給 AI 的提示詞裡，AI 產生文案時會盡量遵守；規則式引擎（未填 API 金鑰時）不會套用此欄位。

🖼 已上傳圖片，若下方填有 API 金鑰，AI 產生貼文時會一併觀察圖片內容並融入文案（需選用支援圖片辨識的模型，如 Claude／GPT-4o／Gemini 系列）；未填金鑰的規則式引擎不會分析圖片內容。

AI 優化設定（選用，需自備 API 金鑰）

金鑰只存在這台電腦的瀏覽器（localStorage），不會送到本工具以外的任何地方。留空時仍可使用「規則式引擎」產生基本優化文案（依平台字數上限截斷、從主題挑關鍵詞組 hashtag），但語意優化效果不如串接 AI。

2貼文預覽與發布

Facebook 卡片可登入你的粉專帳號直接發布；其餘平台請用「複製文字」自行貼到該平台 App／網站；或按右上角「一鍵複製全部」把所有平台的文案一次複製到剪貼簿。

尚未產生貼文——請在上方填寫素材後按「產生優化貼文」。

1粉絲留言與情境

貼上粉絲的留言，選擇想要的回應角度，每個角度會各產生一版回覆，挑最適合的微調後複製貼上即可。

判讀結果：—

回答問題需要的事實（價格、營業時間、退換貨規定、補償方案）請填在這裡，AI 只會引用你提供的資訊，不會自行編造；規則式引擎會留下【待補資訊】標記讓你手動填入。

2回覆建議

每張卡片是一種回應角度，文字可直接修改；按「複製回覆」後貼到該則留言底下回覆。

尚未產生回覆——請在上方貼上留言並按「產生回覆建議」。

使用警語
  • 「產生優化貼文」若填有 API 金鑰會直接連線到你選擇的服務商，金鑰只存在你的瀏覽器 localStorage，本工具不會經手或保存；留空則使用本機規則式引擎，不連網。
  • Facebook 發布功能會透過官方 Facebook JS SDK 登入你自己的帳號並呼叫 Graph API，發布內容將公開出現在你選定的粉專上——按下「發布到 Facebook」前請務必確認內容與粉專無誤，此動作無法復原。
  • Facebook 登入權杖（access token）只存在你的瀏覽器 localStorage，請勿在共用電腦上使用本工具的 Facebook 發布功能。
  • 請勿在任何欄位輸入真實個資、機密資料或受著作權保護的他人內容。
  • AI 生成內容可能有誤，發布前請自行檢查是否符合事實與各平台社群守則；本工具與創作者不對後續發布結果負責。
  • 僅供教學、課程及個人使用，禁止未經授權公開發布、販售或商業化使用。
